# NegiClock · 桌面时钟（普中 HC6800-ES V2.0）

8 位数码管显示时间 / 日期 / 温度，DS1302 走时，DS18B20 测温，4 个按键操作，
2 组闹钟，整点报时，3 档亮度，电脑每 5 分钟自动校时。

---

## 一、功能一览

| 功能 | 说明 |
|---|---|
| 走时 | DS1302，24 小时制，星期由年月日实时算出 |
| 显示 | 25 秒一循环：**15s 时间 → 5s 日期 → 5s 温度** |
| 设置 | 时 / 分 / 秒 / 日 / 月 / 年，逐项调，星期自动 |
| 测温 | DS18B20，`t 23.1c`，负号自动，一位小数 |
| 闹钟 | 2 组，工作日 / 每天 / 一次 / 关闭，响铃方式用小数点直观显示 |
| 整点报时 | 08:00~23:00 每个整点响一声，可开关（D7 指示） |
| 亮度 | 3 档，按键切换 |
| 校时 | 上位机每 5 分钟自动对时，带回执、重发 |

## 二、外设引脚（按原理图核对）

| 外设 | 引脚 | 说明 |
|---|---|---|
| 数码管段码 a~g,dp | **P0.0~P0.7** | 经 74HC573，共阴，高电平亮。573 的 `LE` 由跳线 **J21** 选，要接 **VCC** |
| 数码管位选 | **P2.2 / P2.3 / P2.4** | 74LS138 A/B/C，`Y7`=最左位 … `Y0`=最右位 |
| DS1302 | **P3.6 SCLK / P3.4 I/O / P3.5 CE** | 无纽扣电池，断电丢时间 |
| DS18B20 | **P3.7** | 板上 DS2 位置 |
| 按键（左→右） | **P3.1 / P3.0 / P3.2 / P3.3** | 分别是 `-` / `设置` / `+` / `下一项`，按下为低 |
| 蜂鸣器 | **P2.5**（同时驱 P1.5） | 高电平响，静音时两个脚都低 |
| DA 指示灯 | **P2.1** | 恒低 → DAC0=0V → DA 灯灭 |
| 独立 LED | **P2.0~P2.7** | 低电平亮。D1=接收指示，D6=蜂鸣器脚，D7=整点报时指示 |
| 74HC595 / 点阵 | **P3.4 / P3.6 / P3.5** | 与 DS1302 共用 |
| 串口 | **P3.0 RXD / P3.1 TXD** | CH340，9600 8N1 |

## 三、引脚冲突（重点）

1. **P2.2/2.3/2.4** = 74LS138 位选 ↔ LED **D3/D4/D5**：扫描必然翻转，**关不掉**，会半亮。
2. **P2.1** = DA 电路 ↔ LED **D2**：DAC 要 0V，P2.1 必须恒低 → **D2 常亮**。
3. **P2.5** = 蜂鸣器 ↔ LED **D6**：蜂鸣器静音必须 P2.5 低 → **D6 常亮**。
   （反过来 P2.5 高会让线圈一直通电，只发热不出声。）
4. **P3.4/P3.5/P3.6** = DS1302 ↔ 74HC595 ↔ XPT2046：每次读写时钟后程序都往 595 补送 0xFF 并锁存，
   D9~D16 和点阵保持熄灭。
5. **P3.7** = DS18B20 ↔ XPT2046 的 DOUT：XPT2046 只在 `CS`(P3.5，也就是 DS1302 的 CE) 为低时才驱动
   DOUT，也就是只在**访问 DS1302 的时候**。程序从不在读温度的同时访问 DS1302，所以不冲突。
6. **P3.0/P3.1** = 串口 ↔ 设置/`-` 键：按键 30ms 去抖，串口一字节最多 1ms 低电平，互不干扰。

> 想彻底关掉 D2~D6 只能动硬件：拆 RP7/RP9 排阻（8 个 LED 全灭），或单独焊掉。

## 四、页面与按键

板子上 4 个按键**从左到右**：`-`(DOWN) · `设置`(SET) · `+`(UP) · `下一项`(NEXT)

### 页面
- **Page 0**：时钟页，25 秒循环（15s 时间 → 5s 日期 → 5s 温度）
- **Page 1**：闹钟 A1
- **Page 2**：闹钟 A2

### 平时（不在设置状态）

| 按键 | 时钟页 | 闹钟页 |
|---|---|---|
| **DOWN** | 下一页 | 下一页 |
| **SET** | 进入时间设置 | 进入该闹钟设置 |
| **UP** | 亮度 1→2→3→1 | 亮度（同上） |
| **NEXT** | 整点报时开/关（D7 指示） | 响铃方式：工作日→每天→一次→关闭 |

### 设置状态
- **UP / DOWN**：加减（到边界循环）
- **NEXT**：切换要改的项（时钟：时→分→秒→日→月→年；闹钟：时→分）
- **SET**：保存并退出（时钟会写入 DS1302）

- 设置时当前项 **0.5 秒闪一次**；每次有效按键“滴”一声；按住 UP/DOWN 0.6 秒后连发（连发不响）。

## 五、显示细节

```
时间  14-22-34          日期  12-23  2          温度  t  23.1c
      ↑最右位小数点 1Hz 闪烁                ↑ 't' + 右对齐数值 + 'c'
```

- 温标用字母段：`t` = 0x78，`c` = 0x58；小数点在“个位”那一位上（`|= 0x80`）。
- 负数在数字左边补 `-`；数值右对齐到第 5 格，`125.0` / `-55.0` 都能放下。
- 温度只在温度页读取（每 25 秒一次）：进入温度页时先启动一次转换，800ms 后读回，
  读到新值就显示。这期间关掉定时器中断并消隐，所以不会看到闪烁。

## 六、闹钟

- 显示格式 `A1 13-22`：`A` + 序号 + 空格 + 时 + `-` + 分。
- **8 个小数点就是响铃计划**：前 7 个对应周一~周日，最后一个表示“只响一次”。

| 方式 | 小数点 |
|---|---|
| 关闭 | 全灭 |
| 工作日 | 前 5 个亮（周一~周五） |
| 每天 | 前 7 个全亮 |
| 一次 | 只有最后 1 个亮 |

- 到点后响 **“滴滴滴滴——滴滴滴滴”**（4 短声 + 停顿，循环），按**任意键**停止，
  这一次按键不会触发别的功能；“一次”模式响过之后自动变回“关闭”。
- 连续响约 70 秒没人理也会自动停（不会半夜一直响）。

## 七、上位机

`上位机\NegiClockTool.exe`（双击即用，深色界面 + 托盘）

- **校时页**：绑定串口后立刻校时，之后每 5 分钟一次；只有发送时才打开串口，发完立即关闭。
  收不到回执 1 秒后重发，最多 3 次，失败也继续下一次倒计时。
- **闹钟页**：
  - `从设备同步`：读回板子里的两个闹钟（时间 + 响铃方式）。
  - 改好后点 `写入设备`：开发板“滴”一声、D1 闪 3 下、电脑显示回执。
  - 不同步也能直接改、直接写（以最后写入的为准）。
- 关闭窗口隐藏到托盘，双击图标可再打开。

> 波特率：12MHz 晶振下 `SMOD=1 + TH1=0xFA` 实际是 10417，11.0592MHz 才正好 9600。
> 勾“自动匹配”时会先试 9600，不通再试 10417 / 4808。
>
> 绑定串口时单片机不再复位：板上的 USB 自动下载电路把 CH340 的 `RTS#`/`DTR#` 接到了 RST，
> 而 pyserial 默认在 `open()` 时把它们拉成有效电平。程序改成**在 open() 之前**就设成无效。

## 八、中断与定时器分配（无冲突）

| 资源 | 用途 |
|---|---|
| 定时器0（方式1，0.5ms） | 数码管扫描 / 蜂鸣器方波 / 亮度分帧 / 10ms 节拍 |
| 定时器1（方式2，8 位自动重装） | 串口波特率，`ET1 = 0` 不开中断 |
| 串口中断（高优先级） | 接收帧解析 + D1 闪烁触发 |

`Timer0Init()` 用 `TMOD &= 0xF0; TMOD |= 0x01;`，`SerialBegin()` 用 `TMOD &= 0x0F; TMOD |= 0x20;`，
各自只改自己那半个字节。两个中断服务程序都是叶子函数（内部不调用其它函数），
C51 会自动保存它们用到的寄存器。

亮度：每 8 位一帧，按 4 帧为一个亮度周期，三档分别显示 4/2/1 帧（100% / 50% / 25%）。

## 九、编译与烧录

1. Keil 打开 `0710.uvproj`（现在共 **11 个文件**）。
2. **F7 重新编译**（`Objects\0710.hex` 是旧的，必须重新生成），0 Error 即可。
3. STC-ISP：STC89C52RC → 打开 `Objects\0710.hex` → 下载 → 重新上电。
4. 上电会响一次 **do-mi-sol 三音**；数码管全灭时先检查跳线 **J21 是否在 VCC**。

资源占用：`data = 104.6`（128 字节内）、`code = 4832`（8KB 内）。

## 十一、串口协议

```
PC -> MCU：  A5 5A LEN CMD DATA... XOR
    0x00  心跳（测波特率）                -> 回 ACK
    0x01  校时  LEN=8  YY MM DD W HH MI SS -> 回 ACK
    0x02  读闹钟  LEN=1                    -> 回闹钟数据帧
    0x03  写闹钟  LEN=7  h1 m1 mode1 h2 m2 mode2 -> 回 ACK（并“滴”一声）

MCU -> PC：  A5 5A 01 06 F8               （ACK）
             A5 5A 07 82 h1 m1 mode1 h2 m2 mode2 XOR   （闹钟数据）

mode: 0=关闭 1=工作日 2=每天 3=一次
```

## 十二、已知限制

- 无纽扣电池：断电丢时间，上电先显示 `24-01-01 12:00:00`，等电脑校时后即可。
- D3/D4/D5 半亮，D2、D6 常亮（见第三节），要全黑只能动硬件。
- 设置状态下时钟暂停刷新（正在改时间），闹钟不会在这期间触发。
- 按住“设置/`-`”（P3.0/P3.1）时串口收不到数据，属正常。

## 十三、更新记录

**v7（本次）**
- 修复：上位机校时收不到回执 —— 串口解析把帧长度上限写成了 7，而校时帧长度是 8，整帧被丢掉；
  闹钟写入是 7 所以正常。改回 8。
- 修复：设置时闪烁消失（选中项一直黑）—— 重写 main.c 时把 `BlinkPhase` 的翻转代码漏了。
  现在闪烁用独立的 10ms 计数器（50 次 = 0.5s）在主循环里翻转，和 0.5ms 刷新的定时器彻底分开。
- 修复：温度一直 0.0 —— P3.5 既是 DS1302 的 CE、又是 XPT2046 的 CS。DS1302 每次访问完把 CE 拉低，
  于是 XPT2046 被一直选中，它的 DOUT 也挂在 P3.7 上把总线拉低，DS18B20 读回来就是 0。
  现在测温期间把 CE 拉高（取消选中 XPT2046），并且这 800ms 内不访问 DS1302。
