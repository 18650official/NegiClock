# NegiClock 上位机 · 使用说明

## 运行方式

- 直接双击 **`NegiClockTool.exe`**（和本说明在同一个文件夹里，独立程序，目标电脑不需要装 Python）。
- 或者用源码运行：`pip install pyserial pystray pillow`，然后 `python NegiClock上位机.py`。


## 使用步骤

1. 板子插上 USB，确认设备管理器里能看到 CH340 的串口（如 `COM3`）。
2. 打开程序：
   - **串口**：选刚才那个 COM 口，点“刷新”可重新扫描；
   - **波特率**：默认 9600，保持勾选“自动匹配”即可（握手不通会自动改试 10417 / 4808）；
   - 点 **绑定串口**。
3. 绑定成功会立刻校时一次，状态栏显示 `已绑定 COM3 @ 9600`，并开始 5 分钟倒计时。

### 校时页
- 每 5 分钟自动校时一次：
  - 只有发送的那一下才打开串口，发完立刻关闭，不长期占用；
  - 单片机回 ACK 算成功；没回执就 1 秒后重发，最多 3 次；
  - 3 次都失败也继续下一次 5 分钟倒计时。
- **立即同步** 按钮可随时手动校时。

### 闹钟页
- **从设备同步**：把开发板里的两个闹钟（时间 + 响铃方式）读回来。
- 修改时间/响铃方式后点 **写入设备**：开发板会“滴”一声、D1 闪 3 下，电脑显示“写入成功”。
- 不先读取也可以直接改、直接写（以最后写进去的为准）。

响铃方式：`关闭` / `工作日` / `每天` / `一次`
（开发板上的闹钟页，对应的小数点会点亮，见主 README）

## 文件位置

- 配置：`%APPDATA%\NegiClock\config.json`（记住上次的串口/波特率）
- 日志：`%APPDATA%\NegiClock\negiclock.log`

## 常见问题

| 现象 | 处理 |
|---|---|
| 绑定失败：打开串口失败 | 串口被 STC-ISP / 串口助手占用，先关掉它们 |
| 绑定失败：单片机没有回执 | 检查板子是否上电、烧的是不是 NegiClock 固件；勾选“自动匹配”再试 |
| 绑定成功但过一会儿同步失败 | 板子被复位或 USB 松动；重新点一次“立即同步” |
| 一点“绑定”单片机就响三音复位 | 板上的 USB 自动下载电路把 CH340 的 DTR#/RTS# 接到了 RST。程序已在 `open()` **之前**把 dtr/rts 设成无效来避免；如果还有，把 `open_port()` 里的 `time.sleep(0.35)` 调大 |
| 闹钟写入后板子没反应 | 看日志有没有回执；没有的话重新绑定再试 |
| 双击 exe 没反应 | 少数杀毒软件会拦 PyInstaller 打的包，加白名单即可 |

## 自己重新打包 exe

```bat
pip install pyinstaller pyserial pystray pillow
pyinstaller --noconfirm --onefile --noconsole --name NegiClockTool ^
    --hidden-import pystray._win32 NegiClock上位机.py
```
